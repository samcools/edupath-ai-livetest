# EduPath AI Live Test

WordPress live-test baseline for EduPath AI, integrating the supplied EduPath V11 prototype with Project Guardian operating patterns, Ayanda voice commands, and Microsoft agent mappings.

The installable theme source is stored in `wordpress-theme/edupath-ai-wordpress/`.

See the theme README and `docs/` inside the theme for installation, voice commands, Project Guardian inheritance, and Microsoft agent mapping details.
