# Supplied EduPath V11 prototype inheritance

The WordPress implementation was built from the uploaded EduPath AI V11 ZIP rather than from a blank theme.

Preserved/adapted capabilities include:

- role-selectable portal shell;
- learner, parent, teacher, principal, department, academic-admin and platform-admin journeys, expanded with counsellor, school-admin, University/TVET and employer roles;
- learner records and role-specific dashboards;
- Exam Practice;
- consent-based Exam & Proctoring demo;
- Pathways;
- Applications;
- Funding;
- Work Readiness;
- Notifications;
- settings/administration concepts;
- floating Ayanda assistant pattern;
- eight canonical V11 agents: Learning Guide, Assessment Coach, Pathway Guide, Support Navigator, Work Readiness Coach, Family & Educator Guide, Analytics Guide and Notification Guide.

The WordPress version adds Project Guardian approval/audit patterns, Microsoft agent mappings, secure server proxy boundaries, richer user types, responsive behaviour and deterministic voice command routing.

The uploaded V11 prototype explicitly described authentication, GPT, presence, messages and external integrations as simulated; the WordPress version preserves that honesty by labelling demo behaviour and only claiming external agent execution when a server-side integration is actually configured.
