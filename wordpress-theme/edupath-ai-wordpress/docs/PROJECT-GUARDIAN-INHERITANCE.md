# Project Guardian inheritance

EduPath AI is not rebuilt as an unrelated portal. This theme carries forward Project Guardian operating patterns and adapts them to education.

- Role-aware workspace model.
- Executive dashboard hierarchy.
- One global text/voice assistant.
- Deterministic low-latency routing for clear navigation commands.
- Preview + confirmation for write actions.
- Human review for consequential outcomes.
- Recent activity / audit-event concepts.
- Responsive desktop, tablet and mobile shell.
- Explainable recommendations rather than opaque autonomous decisions.

## Education adaptation

| Guardian pattern | EduPath adaptation |
|---|---|
| Work item | Learning activity, assignment or intervention action |
| Milestone | Learning goal, term outcome or intervention target |
| Project workspace | Learner, class, school or institutional workspace |
| Activity history | Education journey / case history |
| Compliance evidence | Curriculum, privacy, governance and audit evidence |
| Voice command | Learner, educator, administrator and agent instruction |

## Governed action sequence

`User request → deterministic intent → preview → role/permission check → confirmation when required → execution → audit event → UI refresh`

The AI/agent layer must never be able to bypass the authorisation layer.
